# Independent first V4 visual review

The first V4 evaluation set makes visible progress over V3: separate tool mechanisms, can proportions/pictograms, pack straps and pockets, rim thickness, bottle construction and molded grips. It is not yet a Golden 40 match. All 24 remain `REWORK` in this independent qualitative review, with zero visual passes and zero founder approvals. No numerical visual scores are assigned.

This report is tied to the actual PNG snapshots in `reviews/v4_first/`, copied from `/workspace/v4_render_first`. It does not automatically apply to later shader or recipe iterations. Exact per-file hashes are in `V4_FIRST_REVIEW.json`.

## Evidence and priorities

All 24 actual outputs were inspected in `reviews/v4_first/native64.png`, `nearest4x.png` and `v3_vs_v4_native64.png`. The comparison used the actual Golden40 files and the baseline reference boards, not only written descriptions. More detail alone has not yet produced the reference set's physical realism, material differentiation or deliberate local shading clusters.

1. Fix color transformation first: the yellow-green pear is orange-brown, the navy beanie is green, and the amber molded grip is muddy olive-brown. Multiplying an already-colored palette cannot reliably achieve a specified hue.
2. Fix semantic geometry: the gloves have the same thumb side; the rope is a stepped conical stack; wrench jaws need mechanically clear opposing grip surfaces. Keep the requested identities.
3. Fix actual holes and inner-wall geometry: wrench hanging holes are dark filled pixels; the tape bore needs readable wall thickness. Preserve transparency where an unobstructed opening should reveal the background; a thick tape bore can legitimately show an occluding dark inner wall. The mug handle is already correctly open.
4. Replace flat face fills with restrained material-aware shading. The steel bar has a broad pale face; the medical case has planar walls; pack folds create repeated hard diagonal panels. Add local facet/edge/overlap response before adding scratches.
5. Reinspect the weakest individual objects at 32/48/64px after these corrections. Model complexity, hash validity and successful PNG export cannot grant a visual pass.
