# V4 unresolved issues and release gates

1. **The current 24 V4 icons have no founder approval.** Independent technical
   and visual checks are supporting evidence; only the founder can accept this
   newly delivered calibration. No canonical production run beyond24 was launched.
2. **Distinct art remains a design task.** The offline default contains24 original
   masters. The scalable queue can export thousands of jobs, but4,000 distinct
   useful objects still need curated briefs and original geometry/templates.
   Source filenames do not constitute independent shape recipes.
3. **Hybrid authorship must remain explicit.** Default masters were AI-assisted
   source artworks cleaned/quantized at native64. They are not pure procedural
   renders, hand-authored pixel clusters, or proof that a polygon shader alone
   meets Golden40. The procedural-only run remains documented as REWORK.
4. **Actual CodePad/iPhone testing is outstanding.** Documents access, standard
   library availability, app interruptions, storage persistence, thermal behavior
   and practical memory remain device tests. Desktop RSS is not phone RSS.
5. **Visual advisories:** fine fabric/wood texture and radio contrast at32px need
   founder judgment. The native template masters are editable PNGs; future artist
   corrections must be versioned and re-embedded with fresh hashes.
6. **Gameplay integration is intentionally incomplete.** Godot loads all24 textures
   correctly, but none is promoted into the existing runtime item registry. Match
   V3 recipe IDs to current canonical `ll_*` IDs before binding art. World, held,
   directional, damage and gameplay-state views require independent construction.
7. **Variations are not unique designs.** Some seeded tiny scuff choices repeat
   the same pixels. The benchmarks report their exact duplicate counts.100,000
   outputs are not measured here, and large archives/storage grow with job count.
8. **Receipt evidence is a workflow record, not authentication.** The code checks
   exact generator/recipe/output scope and protects approved files, but a JSON
   field cannot authenticate a real founder conversation. Never manufacture an
   approval receipt or reuse an old calibration approval for changed artwork.

The next authorized step after this delivery is review of these24 actual icons.
After acceptance, design100 canonical recipes across accepted families, then
500/1000 with per-family QA. No merge or deployment is included in this work.
