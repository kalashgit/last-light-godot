# LAST LIGHT — Distinct concept intake for eight newer founder sheets

Status: **candidate-only**. Source date: 2026-11-10.

This is an isolated addendum to PR #109, not a main production cursor change.
Eight exact founder-uploaded 1536×1024 JPEGs are SHA-256-pinned by
`tools/foundry_601_650.py`. Original binary sheets are archived privately
in the founder's persistent source package; **not in public Git**. Original
artwork and any incidental trade dress are treated strictly as reference.
Blender re-creates original meshes with blank/generic surfaces, with no logos.

**Number labels are not IDs.** Six sheets each display a nominal 601–650 grid
(300 visual positions), but a particular number denotes *different objects*
across sheets. For example, 601 is canned chili on one sheet and cutting
pliers on another. The other two dense sheets need independent segmentation.
No slot is equated to a Notion master by guesswork.

The pinned snapshot has:

- 8 source-sheet SHA-256 pins; 6 numbered + 2 dense unsegmented;
- 300 known positions, of which **78 observations** are manually grouped into
  **23 provisional distinct physical-object concepts**, and 222 await review;
- eight explicitly selected original geometry recipes;
- zero new Golden approvals and zero canonical Notion IDs;
- one semantic group for each repeated concept, even if it has many appearances;
- separate geometry families to avoid counting recolors of a tin can as new
  physical models.

The Python factory produces one GLB per recipe with distinct component-labelled
meshes, one 64×64 RGBA inventory icon, an eight-way 64×64 atlas (512 px high),
and a four-column inventory sheet. The independent validator checks actual GLB
decoding, hashes, mesh diversity, nondegenerate bounds, sprite alpha, exact
atlas-cell pixels, all world headings, and non-Golden state. CI also converts
all eight into independent editable `.blend` files and imports them in Godot.

**Art QA:** current meshes are small procedural technical approximations.
They do not yet include pixel-perfect edge cleanup, detailed F11 textures,
material wear, real-world/collision scale, interaction animations, 16-heading
F12 renders or physical iPhone FPS. These are explicit remaining gates. The
user's Golden 86–96 sprite style remains a visual reference only; this batch
cannot inherit those approvals. Keep containers isolated and empty.

**No paid AI dispatch**, no deployment, no merge, no Golden promotion. Before
counting additional finished game assets, reconcile the 222 unresolved numbered
slots, both dense sheets, and canonical recipes from Notion. Group repeated
object concepts and designate states/skins as variants, not new original meshes.
