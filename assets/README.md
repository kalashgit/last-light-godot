# Asset import staging (LAST LIGHT V3.6)

This directory is intentionally empty of downloaded art. Assets are **not yet included**.

- Put curated **.png** files from [Kenney Top-down Shooter](https://kenney.nl/assets/top-down-shooter) here to preview 2D sheets and props.
- Put **.glb** or **.gltf** models and their accompanying texture files from [Quaternius Downtown City MegaKit Standard](https://quaternius.itch.io/downtown-city-megakit) here to preview building pieces. Only add a few at once on iPhone.
- Quaternius [Survival Pack](https://quaternius.com/packs/survival.html) ships OBJ/FBX/Blend, so prefer converting chosen models to GLB before use in the asset lab.

To inspect assets, open `asset_lab.tscn` in Xogot and choose **Run Current Scene** (rather than Play Project, which starts the house). Use PREVIOUS/NEXT to browse imported textures/models.

**No house art has been changed yet.** This viewer is for exploration, scaling and selection. 3D models need conversion/rendering or a 2.5D architecture before they replace the Node2D house visuals.
