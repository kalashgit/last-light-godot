# LAST LIGHT — UCF-001 unified content factory pilot

**Status: deterministic world-layout compiler implemented and tested; Godot preview script included but not yet run in Godot or on iPhone.** This is an opt-in scene and does not modify the playable `main.tscn`, existing inventory, or user saves.

The contract lives in [Notion](https://app.notion.com/p/410f639e2373814390a6e56e5278826d). It grows out of the 60 archetype, structural, room and district grammars. UCF-001 deliberately supports *house_small* only until real engine/device tests pass; unsupported types raise a visible error, never masquerade as completed content.

## Generate offline

```sh
python tools/unified_content_factory.py
python tools/unified_content_factory.py --seed 20261107
python tools/unified_content_factory.py --verify data/generated/unified_factory/ucf001_street.json
python -m unittest discover -s tests -p 'test_unified_content_factory.py' -v
```

Standard-library-only. Defaults to the checked-in street recipe or a built-in fallback if the file is absent (useful when running a single copy in CodePad). Files are atomically written. Source is the versioned recipe; output is a deterministic JSON compiler result with stable IDs and independent seeds.

## Experimental Godot preview

Open `res://scenes/unified_factory_street.tscn` manually in Godot. It reads the generated JSON and draws **simple original debug geometry**, with a roof toggle by touch/Space. It does not use final art and is not an interactive survival scene. **Godot execution and on-device compatibility remain unverified.** The world is not activated in `main.tscn`.

## UCF-001 measured foundation

- Three distinct house geometry/layout variants created from one archetype and a common district recipe.
- Twelve functional rooms, three corridors, room/hall/exterior door records, original road/parcel/furniture placement metadata.
- Material IDs and existing asset references but **no original material textures or new Golden 40 art created by this step**.
- Tests check deterministic byte-identical runs, seed-dependent geometry change, unique IDs, room-to-exit connectivity, lot/road access, overlap and invalid archetype rejection.
