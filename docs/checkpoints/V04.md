## Changes
- Fixed multi-touch owner capture, synthetic mouse duplicate handling, focus/cancellation/resize reset and control initialization. Correct inverse 2:1 screen-to-grid movement. Arrow keys, E interact, Space attack, G debug god mode remain.
- Added pause/resume (touch or P/Escape), frozen death state and fresh-world restart (touch or R after death). Pause saves and clears pointers; application focus loss pauses until explicit resume.
- Added schema-1 JSON save: player position/health, supplies, five door open/health states, four searched flags and two zombie positions/health. V3.6 had no persistent schema to migrate. Write temp/flush/rename, validate entire schema before load mutation. Autosave every 15 simulated seconds and on pause/death/restart/close.
- Closed doors/walls block melee in both directions; doors cannot close on player or living zombie. Existing collision substeps, roof cutaway, chase and breach behavior preserved.
- Added automated headless checks, CI workflow, isolated test data directory and graphical screenshot harness. No new asset pack added.
